# Clue Puzzle Customizer

Allow users to upload images to replace current clue scroll puzzle images.

## Description
Clue Puzzle Customizer is a RuneLite plugin designed for Old School RuneScape players who want to personalize their gameplay. This tool allows you to swap out the default sliding puzzle to a custom `.png` or `.jpg`.

## Getting Started

### Dependencies
* **RuneLite Client**: Ensure you are running the latest version of the [RuneLite client](https://runelite.net).
* **OS**: Windows 10/11, macOS, or Linux (anything that supports RuneLite).
* **Java**: The client handles this, but developer builds require JDK 17+. Development using jdk-26.
